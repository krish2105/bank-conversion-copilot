# Bank Conversion Copilot

Cost-optimised targeting for outbound term-deposit campaigns. Score a
prospect or a call list, ranked by expected net value in EUR at a
cost-optimal decision threshold -- not a bare probability.

See the GitHub repository for source, tests, and the full report:
https://github.com/krish2105/bank-conversion-copilot
